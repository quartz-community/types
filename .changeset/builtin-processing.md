Types for Quartz's built-in processing: `GlobalConfiguration.frontmatter` / `links` / `drafts` / `contentIndex`, and the optional `extendContentIndex` hook on plugin instances that adds fields to `contentIndex.json` entries (`ContentDetails` now allows extra fields). `BuildCtx.contentIndex` types the shared content index emitters can reuse.
